# @stratamu/biome

Shared Biome configuration for formatting, linting and import sorting. The `pnpm check` gate only runs `biome format`; run `pnpm biome check` for the lint rules and import sorting. The root `biome.json` extends it.

**Status:** in use. Prints an informational notice that the configuration can be migrated with `biome migrate`; it is not yet migrated.
